| 授权管理 | 批量生成、导入、元数据 CSV 导出、查询、冻结、恢复、作废、设备解绑、授权更换、续费、7/3/1 天站内到期提醒、事件审计 | 邮件/Telegram 到期提醒和续费订单支付闭环 |
| 代理额度 | 管理员分配；代理只读本人额度；按软件/套餐隔离 | 代理向下级转额度（明确禁止） |

| 支付 | 用户充值订单、管理员全站订单查询、收银台、验签回调自动入账、人工钱包入账；EP/EPUSDT/GMPAY 适配基础 | 所有商户生产凭据联调、人工核账/退款审批与全渠道验收 |

| 审计 | 后台分页查询现有审计事件 | 永久归档、防篡改存储与保留策略落地 |
| 区域节点 | 管理员维护区域代码、HTTPS 地址、权重、状态 | 跨区域流量调度、消息队列同步、自动故障切换 |
| 开发者中心 | 协议说明、已注册运行时接口、多语言 SDK 范围、管理员/代理 API Key 及授权 v1 API | 全语言 SDK 发布、自动 API 文档生成流水线 |
| 系统监控 | API 和 MySQL 基础连通性检查 | Redis、队列、节点、QPS/P95/P99、告警和 24 小时压测 |

## 本轮控制台整合

- 侧边栏按工作台、授权业务、用户与代理、财务、安全、开发者、系统管理分组。

- 用户管理增加状态筛选和管理员发起归属变更申请入口；所有变更仍需管理员审批。
