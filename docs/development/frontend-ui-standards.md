# 前端 UI 与页面布局规范

- 文档编号：AUTH-FE-UI
- 版本：V1.0
- 状态：已确认规范

## 1. 技术约束

- 前端使用 React + TypeScript。
- UI 组件统一使用 shadcn/ui，不得自行仿造 shadcn/ui 组件或另造一套组件体系。
- 使用 Tailwind CSS 的统一 spacing scale 管理间距；设计 Token 应集中维护，避免页面各自定义不一致数值。

## 2. 页面结构

- 每个业务页面使用清晰的页面容器、标题区、描述区、操作区和主体内容区。
- 页面区块之间保持一致的垂直间距；推荐页面主容器使用统一的 flex/grid gap 规则。
- 标题、说明、筛选工具栏、统计卡片、表格和分页不得紧贴排列。
- 内容密集时优先使用分组、Tabs、折叠区或分页，不得简单堆叠所有内容。

## 3. 卡片、表单和表格

- 卡片必须有合理内部 padding，卡片之间有明确 gap。
- 统计卡片采用响应式 Grid/Flex；不得使用导致卡片纵向无限拉伸的固定高度。
- 表单字段按统一垂直间距排列；标签、输入框、帮助说明、错误提示之间保持可读距离。
- 表格单元格保持合理内边距；操作按钮之间留有间距；复杂操作收纳进 Dropdown Menu。
- Dialog、Sheet、Popover 等弹层必须保留足够内边距，并保证窄屏可用。

## 4. 响应式与状态

- 桌面、平板、移动端均需适配。
- 窄屏时允许工具栏换行、表单单列、表格横向滚动或使用卡片视图。
- 所有异步页面应具备 Loading、Empty、Error、Success 状态。
- 必须测试长标题、长文本、超长表格、无数据、权限不足和网络失败场景。

## 5. 视觉验收

每个页面合并前检查：
1. 页面边缘与内容容器留白合理。
2. 标题、描述、操作区、卡片、表格之间有一致间距。
3. 卡片和弹层内部没有文字贴边。
4. 表单字段与按钮之间没有拥挤或误触。
5. 不存在大面积无意义空白、固定高度拉伸或内容重叠。
6. 不同屏幕宽度下无溢出、遮挡和不可操作控件。
7. 使用 shadcn/ui 标准组件与一致的交互状态。
