## 已由需求方确认并关闭的 V1.3 事项

### 角色、用户与代理
- 角色包括管理员、代理、下级代理、用户。
- 支持代理创建用户和用户自主注册；自主注册且没有邀请码/代理归属的用户进入公共用户池，由管理员分配。
- 用户或管理员均可发起变更代理归属申请，最终由管理员审批。
- 代理售价由管理员统一设置，代理不能自行设置售价。
- 只有管理员可以分配授权额度；代理不能自行向下级代理转额度。
- 管理员拥有全站权限；代理 API 只能操作自身授权范围内的资源。

### 授权业务
- 套餐由管理员维护：月卡、季卡、年卡、永久卡。
- 一机一码，支持换机，换机次数不限制。
- 永久授权永不过期，但管理员仍可冻结、恢复、作废。
- 支持批量生成、导入、导出授权。
- 到期前 7 天、3 天、1 天提醒。
- 续费是否消耗额度按软件独立配置。

### API、SDK 与安全
- 管理员 API Key 可使用全站权限；代理 API Key 仅能开通、更换、查询自身范围授权，查询用户和下级等授权范围数据。
- 软件身份凭据独立于管理员/代理 API Key。
- SDK 目标语言包括 C#、C++、C、Java、Kotlin、Go、Python、JavaScript、TypeScript、PHP、Rust、易语言，后续可扩展。
- 签名使用 RSA-3072 + SHA-256，填充为 RSA-PSS；平台私钥由 KMS/HSM 托管，客户端只持有验签公钥。
- 软件身份凭据支持平台生成管理或开发者自行生成上传。
- 离线授权按软件独立配置 0～90 天，0 表示禁用。
- 密钥泄露支持紧急撤销、轮换、强制客户端升级和审计。

### 全球部署与性能
- 国内、海外使用独立授权集群和独立数据库，流量规划比例各 50%，统一管理后台。
- 区域间通过消息队列同步允许跨区域流转的数据。
- 网络中断时，有效缓存租约内的授权继续验证；新授权和管理操作暂停；恢复后幂等补偿和对账。
- 重要状态变更跨区域传播目标 1 秒以内（仅链路正常时目标）。
- 每区域持续 80,000 QPS、连续 24 小时；服务端 API P95 ≤50ms、P99 ≤100ms；可用性目标 99.99%。以上必须实测，不得当作已达成能力。

### 财务、币种与支付
- 平台支持 CNY 和 USDT 两种独立结算单位：CNY 展示 ¥，USDT 展示 U。
- CNY 与 USDT 独立余额、独立订单、独立价格、独立流水；不做汇率换算、自动兑换或跨币种抵扣。
- 充值支持管理员手动充值和在线支付；在线支付成功自动入账，手动充值经管理员确认。
- 支付渠道范围：支付宝官方接口、微信支付官方接口、易支付、EPUSDT、GMPAY。
- EPUSDT 和 GMPay 必须适配正式商户协议提供的托管收银台模式；具体字段、签名和回调必须依据官方文档和商户版本。
- 授权额度购买订单不支持退款；资金差错通过可审计冲正/纠错流程处理，不得篡改流水。
- 财务流水和安全审计日志永久归档；普通运行日志保留 180 天。

### 通知、前端与交付
- 通知渠道包括站内通知、邮件、Telegram 机器人及可扩展渠道。
- 前端必须使用 React + TypeScript + shadcn/ui，不得自行仿造替代组件。
- 所有页面必须遵循统一留白、组件间距、卡片 padding 和响应式布局规范。
- 所有代码变更必须通过 PR；自动化测试、代码规范和安全扫描必须通过。
- 测试环境自动部署；生产环境由管理员批准。
- 自动生成开发文档并经过人工审核。
