# 待确认事项清单

本清单只列出尚未由用户明确确认的事项。任何建议都不得自动升级为已确认需求。

## 全球部署与一致性
- 管理控制平面部署在何处，是否需要双区域管理入口？
- 国内/海外哪些数据需要同步，哪些数据必须区域留存？
- 授权状态变更跨区域最大允许传播延迟是多少？
- 网络分区期间，冻结、作废、换机和新激活分别采用何种允许/拒绝策略？
- 主写区域、冲突解决、故障切换和恢复流程是什么？
- 每区域 80,000 QPS 的验收持续时间、错误率和延迟阈值？
- 可用性目标、RPO、RTO 是多少？

## 性能与日志
- 授权验证 P95/P99 目标是否分别设定？
- 成功验证聚合统计粒度（分钟/小时/日）及保留期限？
- 异常日志、审计日志、财务流水各自保留期限？
- 是否要求日志不可篡改存储及合规归档？

## 授权业务
- 续费是否再次消耗授权额度？
- 是否需要批量生成、导入、导出授权？
- 授权到期提醒是否需要，采用哪些通知渠道？
- 用户是否可以变更所属代理，转移需谁审批？
- 代理是否可自定义面向用户的零售价？
- 未归属代理的自主注册用户如何分配？
- 永久授权的定义及软件停服后的处理规则？

## 客户端与离线
- 多客户端具体平台清单（Windows、Linux、Android、iOS、Web、服务端等）？
- 首批 SDK 语言优先级？
- 每个软件离线时长的最大上限？
- 离线凭证续租、时钟回拨和设备重置策略？
- 是否需要 iOS 支持？

## 密钥与接入
- RSA 签名填充最终采用 RSA-PSS 还是兼容性所需的其他明确配置？
- 平台私钥是否统一使用 KMS/HSM，具体部署形态？
- 软件服务端密钥由软件方自行保管还是平台托管？
- App Secret 是否需要支持多凭据并行及细粒度权限？
- 公钥分发、吊销列表和客户端公钥更新机制？

## 财务
- 在线支付渠道及币种？
- 充值退款规则、支付手续费和对账周期？
- 代理购买价格是否按软件/套餐/代理等级分别配置？

## 开发交付
- 主分支保护规则、必须审核人数及 CODEOWNERS 范围？
- CI 测试、安全扫描和发布环境要求？
- 文档自动生成工具及正式发布权限？
## 已由需求方确认并关闭的事项（V1.3）

以下事项已确认，不再列为待决策：
- 续费是否消耗额度：按软件独立配置。
- 代理售价：管理员统一设置，代理不可自行设置。
- 用户代理归属转移：用户或管理员可发起申请，管理员最终审批。
- 自主注册无代理用户：进入公共用户池，由管理员分配。
- 批量授权：支持批量生成、导入、导出。
- 到期提醒：到期前 7 天、3 天、1 天。
- 永久授权：永不过期，但管理员保留冻结、恢复、作废等管理权。
- 全球架构：国内、海外独立数据库和授权集群，消息队列跨区域同步；统一管理后台。
- 网络分区：有效缓存授权继续验证，新授权和管理操作暂停；恢复后补偿对账。
- 重要状态变更跨区域同步目标：1 秒以内（仅链路正常时的目标）。
- 性能验收：每区域连续 24 小时 80,000 QPS；P95 ≤ 50ms、P99 ≤ 100ms；可用性目标 99.99%，均需实测。
- 签名：RSA-3072 + SHA-256，RSA-PSS；平台私钥 KMS/HSM 托管。
- 软件身份凭据：平台生成管理或开发者生成上传两种模式。
- SDK 语言：C#、C++、C、Java、Kotlin、Go、Python、JavaScript、TypeScript、PHP、Rust、易语言。
- 离线授权：每软件独立配置 0～90 天，0 表示禁用。
- 密钥泄露：支持紧急撤销、轮换、强制升级和审计。
- 结算：多币种由管理员配置；精确账务，禁止浮点运算。
- 充值：管理员手动充值 + 在线支付；在线支付自动入账，手动充值经管理员确认。
- 授权额度购买订单不支持退款；资金差错通过可审计冲正纠错。
- 代码审核：所有变更必须 PR 审核；自动化测试、规范检查和安全扫描必须通过。
- 发布：测试环境自动部署，生产环境管理员批准。
- 日志：财务和安全审计永久归档，普通运行日志 180 天。
- 通知：站内、邮件、Telegram 及可扩展渠道。
- 前端：React + TypeScript + shadcn/ui；每页必须有一致留白、组件间距、卡片 padding 和响应式布局，禁止内容拥挤或无意义空白。

- 首批 SDK 的发布顺序、各语言最低运行时版本和平台测试矩阵（目标语言范围已确认）。
- 国内/海外数据字段级同步白名单、数据驻留和跨境合规评估。
- 区域网络分区期间各类管理操作的细分拒绝/排队策略，以及 RPO/RTO。
- 到期提醒的具体通知模板、重试策略、用户通知偏好和各渠道配置。
- KMS/HSM 供应商、部署形态、密钥备份与灾备演练细节。
- 在线支付渠道、商户接入、手续费承担和对账周期。
- 主分支保护、CODEOWNERS、CI 执行环境和发布流水线的具体配置。
