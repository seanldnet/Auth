# 币种与支付渠道最终确认

## 币种
- CNY 与 USDT 为两种独立记账单位。
- CNY 展示人民币符号 ¥；USDT 展示 U。
- 不做任何汇率换算，不提供币种兑换，不允许不同币种余额混用。
- 订单、余额、价格、流水均保留币种字段且分别核算。

## 支付渠道
必须纳入支付宝官方支付接口、微信支付官方支付接口、易支付、EPUSDT、GMPAY。
EPUSDT 与 GMPAY 特别要求支持正式商户文档所定义的收银台模式，以及适用的 API 下单、异步通知和查单流程。真实商户联调需要对应商户文档、测试商户账号及测试密钥，不得臆造接口协议。

## 到账
- 在线支付：经服务端验签或可信查单确认成功后自动入账。
- 管理员手动充值：管理员确认后入账。
- 支付回调必须幂等；浏览器同步跳转不得直接入账。
